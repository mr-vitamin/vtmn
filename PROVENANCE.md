# Development provenance

VTMN began from a Lovable-generated application scaffold and includes subsequent owner-directed development with software-assistant support. Original scaffold and third-party contributions are acknowledged; this snapshot does not claim that every component was independently authored from scratch by VTMN.

The current application uses independently maintained Vite, React, and TanStack configuration. The original editor is not required to build it. Electric Genesis was developed and approved before its integration into the portfolio. This public-facing source snapshot intentionally starts a new Git history; the full development record is retained separately by the owner.

Third-party packages retain their own licenses. Inter font software is attributed to The Inter Project Authors and remains under SIL OFL 1.1. Notices are included at public/fonts/Inter-OFL.txt and src/assets/brand/Inter-OFL.txt. The self-hosted website font is Inter. The web lockup contains an Inter Light motto subset from Google's Inter distribution, under the same font license.

The legacy Syne-derived outlines in src/lib/wordmark-geometry.ts preserve their Google Fonts source attribution. No Syne font binary is bundled, and the font's authorship is not claimed as original VTMN work. See the [official Syne font license](https://github.com/google/fonts/blob/main/ofl/syne/OFL.txt).

Original branding and identified artwork are separately reserved in BRANDING.md. Apache 2.0 applies only to software code that the owner has rights to license; third-party rights are not replaced by that grant.
